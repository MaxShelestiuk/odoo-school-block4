# hr_hospital — Odoo 19

Модуль Odoo розміщений у директорії `hr_hospital/` на один рівень нижче кореня репозиторію.

Я також розглядав варіант розміщення модуля безпосередньо в корені репозиторію, але відмовився від нього, оскільки технічна назва модуля Odoo визначається назвою директорії модуля. Після звичайного `git clone` назва директорії репозиторію може відрізнятися від `hr_hospital`, через що XML ID на кшталт `hr_hospital.some_record` можуть більше не посилатися на цей модуль коректно.
